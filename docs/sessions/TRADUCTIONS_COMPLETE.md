## 🎯 Utilisation

### Changer de langue dans l'application

```typescript
import { useTranslation } from 'react-i18next'

const { t, i18n } = useTranslation()

// Changer la langue
i18n.changeLanguage('es') // fr, en, it, es

// Utiliser une traduction
t('dashboard.welcome') // "Bienvenue" (FR) / "Welcome" (EN) / "Benvenuto" (IT) / "Bienvenido" (ES)
```

### Ajouter une nouvelle traduction

1. Ajouter la clé dans `fr.json` (langue de référence)
2. Traduire dans `en.json`, `it.json`, `es.json`
3. Utiliser avec `t('category.key')`

### Exemple

```json
// fr.json
{
  "dashboard": {
    "newFeature": "Nouvelle fonctionnalité"
  }
}

// en.json
{
  "dashboard": {
    "newFeature": "New feature"
  }
}
```

```tsx
// Dans un composant
<h1>{t('dashboard.newFeature')}</h1>
```

## 📝 Notes Techniques

### Structure des fichiers de traduction

```json
{
  "category": {
    "key": "Traduction",
    "nestedCategory": {
      "nestedKey": "Traduction imbriquée"
    }
  }
}
```

### Interpolation

```typescript
// Avec variables
t('dashboard.welcome', { name: 'John' })
// "Bienvenue, John"

// Avec pluriels
t('common.results', { count: 5 })
// "5 résultats"
```

### Fallback

Si une clé n'existe pas dans la langue active, le système utilise :
1. La langue de fallback (français)
2. La clé elle-même si aucune traduction n'existe
