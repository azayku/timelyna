# Frontend Instructions — React 19 & Tailwind 4

Specific rules for the `frontend-v2/` directory of Timelyna.

## 🏗 Architecture: Feature-Sliced Design (Light)
Organize code by features in `src/features/`. Each feature should contain:
- `api.ts`: TanStack Query hooks and API calls.
- `components/`: Feature-specific UI components.
- `types.ts`: TypeScript interfaces for the feature.
- `store.ts`: Zustand store for local feature state (if needed).

## ⚛️ React & TypeScript Rules
- **Version:** React 19 (use `useActionState` where appropriate).
- **Components:** Functional components with arrow functions.
- **Props:** Define interfaces for all component props.
- **Hooks:** Custom hooks for reusable logic, prefixed with `use`.

## 🎨 Styling (Tailwind 4)
- Use Tailwind utility classes for all styling.
- Minimize custom CSS files.
- Support dark mode using `dark:` variants.
- Use `lucide-react` for icons.

## 🛠 State Management & Data Fetching
- **Server State:** TanStack Query (React Query) for all API interactions.
- **Global State:** Zustand for authentication, theme, and common app state.
- **Forms:** React Hook Form + Zod for validation.
- **Grids:** AG Grid for data-heavy views.

## 🌐 Globalization (i18n)
- Use `react-i18next`.
- Never hardcode user-facing strings.
- Keys should be snake_case in `public/locales/`.

## 🧪 Testing
- Use `Vitest` and `React Testing Library`.
- Test user interactions, not just rendering.
- Mock API calls using MSW (if available).
